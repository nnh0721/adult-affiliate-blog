## 守る原則
1. 公式素材のみ。画像は商品メイン画像・サンプル画像、拡大・縮小のみ。説明文・レビューの引用はしない。
2. リンク付き投稿は先頭に【PR】。承認前にリンクは使わない。
3. 感想は観た作品だけ。観ていない作品は事実（価格・期限・順位）だけ。
4. 暴力・強要・犯罪を前面に出した作品、未成年を連想させる作品、近親設定は紹介しない。
5. 他人の投稿へのリンク付きリプ、DMでの配布、Xの広告、自分のリンクでの購入はしない。
6. 投稿はスクリーンショットかログで保存する（運営から開示を求められた場合に備える）。
